# Deploy Hardcount

This folder holds the files to run Hardcount with Docker Compose. Pick the row that matches what you want.

| I want to | Read |
|---|---|
| Try Hardcount on my own computer, in about five minutes | [Quick start](../README.md#quick-start), which runs [`compose/quickstart.sh`](compose/quickstart.sh) |
| Run Hardcount on one server, for real use by a small team | [Production on one VM](../docs/production-one-vm.md) |
| Run two or more copies, so a restart causes no downtime | [High availability](../docs/ops/high-availability.md) |

Settings, Postgres, upgrades and monitoring, for any of these: [Self-host](../docs/self-host.md).
