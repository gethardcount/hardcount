# Deploy Velox

This folder holds the files to run Velox with Docker Compose. Pick the row that matches what you want.

| I want to | Read |
|---|---|
| Try Velox on my own computer, in about five minutes | [Quick start](../README.md#quick-start), which runs [`compose/quickstart.sh`](compose/quickstart.sh) |
| Run Velox on one server, for real use by a small team | [Install on one VM](compose/README.md) |
| Run two or more copies, so a restart causes no downtime | [High availability](../docs/ops/high-availability.md) |

Settings, Postgres, upgrades and monitoring, for any of these: [Self-host](../docs/self-host.md).
